# User Journeys

> Status: Baseline V1 — subject to final architecture audit.

## Purpose
Define end-to-end operator journeys.

## Research journey

Owner asks Master AI → task created → research agents investigate → experiment produced → evidence reviewed → candidate registered.

## Trading journey

Market context → strategy signal → OrderIntent → Risk → OMS → Execution → Fill → Reconciliation → Portfolio → Ledger.

## Incident journey

Alert → kill/pause → containment → reconciliation → diagnosis → recovery → post-incident review.

## Promotion journey

Candidate → backtest → WFO → OOS → stress → shadow/demo → validation → approval → deployment.
