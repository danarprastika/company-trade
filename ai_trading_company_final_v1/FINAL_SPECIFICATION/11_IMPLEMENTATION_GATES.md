# Implementation Gates — Final

G0 Specification integrity: all normative docs versioned and cross-referenced.
G1 Domain foundation: canonical IDs, time, money, events, errors.
G2 Data/market: providers, quality, calendars, instruments.
G3 Trading core: signals, intents, risk, OMS, simulated execution.
G4 Research: datasets, backtest, walk-forward, OOS, stress, replay.
G5 AI Company OS: registry, tasks, tools, memory, evaluation, supervision.
G6 Demo/Shadow: isolated portfolios and promotion evidence.
G7 Web/Telegram: governed command path and audit.
G8 Broker adapters: sandbox/demo certification and reconciliation.
G9 Security/operations: secrets, observability, backup, recovery, chaos.
G10 Production readiness: all tests/evidence pass and live gate approved.
G11 Live: enable only after explicit production approval and legal/provider eligibility.

No gate may be skipped by changing configuration.
