## Language architecture

Frontend:
- TypeScript
- HTML
- CSS
- optional Rust/WASM for justified browser-side computational modules

Backend:
- Go
- Rust for explicitly justified safety-critical modules
- SQL for persistence

Intelligence:
- Python

Infrastructure:
- IaC

## Quality rule

Language diversity is not used as security-by-obscurity. Each language exists for a concrete responsibility and must pass the same production quality gates.
